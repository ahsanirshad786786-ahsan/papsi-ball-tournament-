# Pepsi Ball Tournament — Phone Build

## Build APK from your phone
1. Create a free GitHub account at https://github.com/
2. Create a new **public or private** repository, for example `PepsiBallTournament`.
3. Upload the **contents** of this project (not just the ZIP file) to the repository.
4. Open the **Actions** tab and select **Build Pepsi Ball Tournament APK**.
5. Tap **Run workflow**.
6. When the workflow finishes, open the completed run and download the artifact named **PepsiBallTournament-debug-apk**.
7. Extract the downloaded artifact and install `app-debug.apk` on Android. You may need to allow installation from your browser/file manager.

The workflow builds the debug APK in GitHub's cloud, so Android Studio is not required on the phone.
